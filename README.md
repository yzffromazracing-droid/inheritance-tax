# 相続税区分辞書

国税庁ホームページに掲載されている相続税・贈与税・財産評価の資料を収集し、区分とキーワードで調べられるようにした辞書アプリです。
画面構成は法人税区分辞書に合わせています。

## 画面

| タブ（サブタブ） | 内容 |
| --- | --- |
| 辞書（横断検索） | 収録しているすべての通達・記事の横断検索。資料の種類（相続税法基本通達・財産評価基本通達・措置法通達・個別通達・タックスアンサー・質疑応答事例・文書回答事例）のボタンと分類で絞り込めます（最初に開く画面） |
| 辞書（事業承継） | 中小企業庁ホームページ「事業承継」の内容（事業承継を知る・進め方・支援策・事業承継税制・ガイドライン・資料・新着情報）を整理し、関係する国税庁の措置法通達・タックスアンサーとつないだもの |
| 辞書（相続税） | 区分（税率、納税義務者、相続人と法定相続分、相続財産、非課税財産、債務控除と葬式費用、生前贈与の加算、課税価格と税額の計算、税額控除、遺産分割、小規模宅地等の特例、申告と納付、延納と物納、納税猶予）を選ぶと、テーマごとの説明と関係する通達・記事のタイトルを一覧にします。「すべて」では横断検索します |
| 辞書（贈与税） | 同じく贈与税の区分（税率、納税義務者、贈与財産とみなし贈与、非課税財産と非課税制度、暦年課税の計算、贈与税の配偶者控除、相続時精算課税、土地の無償使用、申告と納付、納税猶予） |
| 辞書（財産評価） | 相続税・贈与税に共通する財産の評価の区分（早見表、評価の原則、土地・家屋の評価、株式・出資の評価、その他の財産の評価） |
| 国税庁の記事 | タックスアンサー / 質疑応答事例 / 文書回答事例 |
| 通達 | 相続税法基本通達 / 財産評価基本通達 / 措置法通達 / 個別通達 |

- スペース区切りで AND 検索、「-語」で除外、通達番号（`3-1`、`69の4-1`）でも検索できます
- 「税率」の区分には、相続税の速算表・基礎控除額・2割加算、贈与税の一般税率・特例税率の速算表・基礎控除・相続時精算課税の税率を表で載せています
- 財産評価タブの「早見表」には、地目別の評価方式、権利関係に応じた宅地の評価算式、借地権割合、家屋、上場株式、取引相場のない株式の評価方式と会社規模の判定基準、その他の財産の評価方法を表で載せています
- ひらがな・カタカナの読み（例：`かしやたてつけち`、`れきねんかぜい`）でも検索できます
- 項目を開くと全文（表・注書きを含む）と国税庁の原文リンクを表示します
- 本文中の「相基通」「評基通」「措通」の番号や、収録済みのページへのリンクは辞書の中で開きます
- 各項目に、属する相続税・贈与税・財産評価の区分のテーマを表示し、押すとそのテーマの一覧に移動します

## 使い方

```sh
python3 -m http.server -d docs 8000
# http://localhost:8000/ を開く
```

`docs/` は静的ファイルのみで構成されているため、GitHub Pages（Settings → Pages → `docs/` フォルダ）でそのまま公開できます。

## 辞書データの更新

```sh
pip install requests beautifulsoup4 lxml
python3 scraper/build_dictionary.py   # docs/data/dictionary.json を再生成
python3 scraper/build_yomi.py         # 読み表に scraper/yomi_extra.tsv の用語を追加
```

取得した HTML は `.cache/nta/` に保存され、再実行時は再利用されます。最新の内容を取り直すときは
キャッシュを削除してから実行してください。アクセス間隔は `--delay`（秒）で調整できます。

相続税タブ・贈与税タブ・財産評価タブの区分とテーマ（説明文と割り当て規則）は `scraper/bunrui.py` にあります。
割り当ては目次の見出し・タックスアンサーのコード番号・タイトルの語句によるもので、本文の内容から推測はしていません。

読み表 `docs/data/yomi.json` は法人税区分辞書の読み表に、相続税・贈与税の用語（`scraper/yomi_extra.tsv`）を加えたものです。

## 事業承継タブ（中小企業庁の情報）

中小企業庁のサイトはこの辞書の自動取得の対象にできなかったため、「事業承継」入口ページと
「事業承継を知る」「事業承継を実施する」「事業承継の支援策」の各ページ（2026年10月30日時点）の内容を
`scraper/shoukei.py` に手作業で整理しています。国税庁の事業承継税制の通達・記事との対応付けも同じファイルにあります。
中小企業庁のページが更新されたときは、このファイルを書き換えて `scraper/build_dictionary.py` を実行してください（月次の自動更新では更新されません）。

## 月次の自動更新

`.github/workflows/monthly-update.yml`（GitHub Actions）が毎月2日 6:17（日本時間）に次の処理を行います。

1. 国税庁ホームページから、収録しているすべての通達・記事を取得し直す（キャッシュは使わない）
2. 前回のデータ（`docs/data/dictionary.json`）と項目ごとに比べ、追加・削除・更新された項目を調べる
3. 変更があれば `docs/data/dictionary.json` と更新記録 `docs/data/updates.json` をコミットし、GitHub Pages を再ビルドする
   （変更がなければ何もしない。コミットメッセージと Actions の実行結果の画面に変更の一覧が出ます）

- 前回より項目数が3％を超えて減った場合は、取得の失敗とみなして更新を中止します（Actions の実行が失敗として記録されます）
- 新しく追加された項目のうち、相続税・贈与税・財産評価の区分に当てはまらなかったものはコミットメッセージに書き出します。必要なら `scraper/bunrui.py` に規則を足してください
- アプリの辞書タブの「最近の更新」に、直近の更新で追加・更新・削除された項目が表示されます
- すぐに更新したいときは、GitHub の Actions → 「国税庁データの月次更新」→「Run workflow」で手動実行できます

手元で同じ処理を行う場合：

```sh
python3 scraper/build_dictionary.py --only-if-changed --report update-report.md
```

## 注意

- 出典：国税庁ホームページ（https://www.nta.go.jp/）。収録内容は取得日時点のものです。
- 区分・テーマの説明は本辞書による概要です。実際の適用にあたっては、原文と最新の法令・通達を必ず確認してください。
