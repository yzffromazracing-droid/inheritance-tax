# 相続税区分辞書

国税庁ホームページに掲載されている相続税関係の資料を収集し、ひとつの索引から検索・閲覧できるようにした辞書アプリです。

## 収録内容

| 種類 | 出典 | 件数 |
| --- | --- | ---: |
| 通達 | 相続税法基本通達 | 442 |
| 通達 | 財産評価基本通達 | 271 |
| 通達 | 租税特別措置法（相続税法の特例関係）の取扱いについて | 978 |
| タックスアンサー | 相続税・贈与税・財産の評価（コード41xx〜46xx） | 109 |
| 質疑応答事例 | 相続税・贈与税 | 147 |
| 質疑応答事例 | 財産の評価 | 172 |

（2026-10-25 取得時点。合計 2,119 件）

各項目には、出典どおりの目次区分（章・節・条関係など）に加えて、資料の種類を横断する
**相続税区分**（小規模宅地等の特例、土地等の評価、みなし相続財産、納税猶予 など 20 区分）を付与しています。

## アプリの機能

- キーワード検索（空白区切りで AND 検索、通達番号 `3-1` / `69の4-1` でも検索可）
- 資料の種類・相続税区分・出典の目次による絞り込み（件数つき）
- 本文表示（表・注書きを含む）と国税庁の原文へのリンク
- 本文中の「相基通」「評基通」「措通」番号や、収録済みページへのリンクを辞書内で開く
- 同じ区分の関連項目（通達・タックスアンサー・質疑応答事例を横断）
- 各項目の URL（`#t-...`）で直接開ける
- スマートフォン表示、ダークモード対応

## 使い方

```sh
python3 -m http.server -d docs 8000
# http://localhost:8000/ を開く
```

`docs/` は静的ファイルのみで構成されているため、GitHub Pages（Settings → Pages → `docs/` フォルダ）でそのまま公開できます。

## 辞書データの更新

```sh
pip install requests beautifulsoup4 lxml
python3 scraper/build_dictionary.py           # docs/data/dictionary.json を再生成
```

取得した HTML は `.cache/nta/` に保存され、再実行時は再利用されます。最新の内容を取り直すときは
キャッシュを削除してから実行してください。アクセス間隔は `--delay`（秒）で調整できます。

相続税区分の分類規則は `scraper/build_dictionary.py` の `TOPICS` にあります。
